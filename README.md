# lab-01

Лабораторна робота №1 — FPV Drone Arena
Тема

Дослідження виконання JavaScript, циклу подій та побудова базового ігрового циклу для браузерної гри на Canvas 2D.

Мета роботи

Метою лабораторної роботи є практичне дослідження особливостей виконання JavaScript у браузері та створення базового ігрового циклу для 2D-гри.

У роботі реалізовано гру на тему FPV-дронів. Гравець керує дроном за допомогою клавіш WASD або стрілок. Рух дрона виконується за допомогою фізичної моделі з прискоренням, швидкістю та тертям.

Використані технології
JavaScript;

requestAnimationFrame;

Структура проєкту

Проєкт складається з декількох модулів.

main.js — точка входу в програму.

game.js — основна логіка гри та створення стану дрона.

loop.js — реалізація ігрового циклу з фіксованим кроком симуляції.

input.js — обробка клавіатури за допомогою замикання.

physics.js — фізика руху FPV-дрона.

render.js — малювання ігрової сцени та дрона на Canvas.

style.css — оформлення інтерфейсу та HUD.

Ігровий цикл

Для створення циклу використовується requestAnimationFrame.

Оскільки частота виклику requestAnimationFrame залежить від частоти оновлення монітора, вона не використовується безпосередньо для розрахунку фізики.

Для фізики використовується фіксований крок:

dt = 1 / 60

Таким чином, симуляція виконується 60 разів на секунду незалежно від частоти оновлення дисплея.

Між кроками симуляції використовується інтерполяція, завдяки якій рух об'єкта під час рендерингу виглядає плавним.

Керування

Для керування дроном використовуються:

W або стрілка вгору — рух вперед;
S або стрілка вниз — рух назад;
A або стрілка вліво — рух ліворуч;
D або стрілка вправо — рух праворуч;
ESC — повернення дрона в центр арени.
Замикання

Функція createInput() використовує замикання.

Стан натиснутих клавіш зберігається у змінній keys, яка є локальною для функції.

Зовнішній код не має прямого доступу до цієї змінної. Для перевірки стану клавіші використовується метод isPressed().

Такий підхід дозволяє приховати внутрішній стан модуля та забезпечити інкапсуляцію.

Фізика

Функція integrate() відповідає за зміну стану дрона.

Вона отримує:

поточний стан дрона;
стан клавіатури;
фіксований часовий крок;
розміри арени.

Функція не залежить від DOM та Canvas, тому є чистою частиною логіки симуляції.

Під час руху змінюються координати, швидкість та напрямок дрона.

Canvas 2D

Для відображення гри використовується Canvas 2D API.

Розмір Canvas адаптується до розміру вікна браузера.

Також враховується devicePixelRatio, завдяки чому графіка коректно відображається на дисплеях із високою щільністю пікселів.

Wrap-around

У грі реалізовано загортання країв арени.

Якщо FPV-дрон залишає арену через праву межу, він з'являється з лівого боку.

Аналогічний принцип працює для верхньої та нижньої межі.

HUD

На екрані відображаються три показники:

Steps/s — кількість кроків симуляції за секунду;
Frames/s — кількість кадрів за секунду;
Frame time — час виконання поточного кадру.

На дисплеї з частотою 144 Hz очікується приблизно 60 кроків симуляції за секунду та близько 144 кадрів рендерингу за секунду.

Висновок

У лабораторній роботі було створено базову браузерну гру на тему FPV-дронів.

Було практично реалізовано роботу ES-модулів, замикань, Canvas 2D API та requestAnimationFrame.

Для фізики використано fixed timestep із частотою 60 кроків на секунду. Це дозволяє відокремити швидкість симуляції від швидкості рендерингу та отримати передбачувану поведінку гри на моніторах із різною частотою оновлення.

Створена архітектура може бути використана як основа для подальшого розвитку проєкту та додавання мережевої взаємодії через Node.js.
